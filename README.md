# Moonwalk

Moonwalk is a space-themed restaurant ordering app. Customers can place orders and track a countdown for each order while it is being prepared.

## Prerequisites

- Java 25 (the backend's configured Java version)
- Node.js 18 or newer and npm

The backend uses an embedded in-memory HSQLDB database, so no separate database installation or setup is needed. Its data is cleared when the backend stops.

## Run locally

Run the backend and frontend in separate terminals. Start the backend first so the frontend can reach its API.

### 1. Start the backend

From the repository root, run:

```powershell
cd Moonwalk
.\mvnw.cmd spring-boot:run
```

The backend starts at `http://localhost:8080`. On macOS or Linux, use `./mvnw spring-boot:run` instead of `.\mvnw.cmd`.

### 2. Populate the initial database state

The database is empty each time the backend starts. Before opening the frontend, register at least one chef and add menu items. In PowerShell, use `curl.exe` (rather than the `curl` alias).

Register a chef (the endpoint accepts form data):

```sh
curl -X POST http://localhost:8080/chefs/insert-chef -H "Content-Type: application/x-www-form-urlencoded" -d "chefName=Alex"
```

Add menu items (item IDs are generated by the backend):

```sh
curl -X POST http://localhost:8080/item/insert-item -H "Content-Type: application/json" -d '{"itemName":"Moon Burger","itemValue":450,"preparationTime":12}'
curl -X POST http://localhost:8080/item/insert-item -H "Content-Type: application/json" -d '{"itemName":"Stardust Fries","itemValue":180,"preparationTime":5}'
curl -X POST http://localhost:8080/item/insert-item -H "Content-Type: application/json" -d '{"itemName":"Cosmic Shake","itemValue":220,"preparationTime":3}'
```

You can check that the items were added with:

```sh
curl http://localhost:8080/item/get-all-items
```

### 3. Start the frontend

In a second terminal, from the repository root, run:

```powershell
cd MoonwalkFrontend
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`). The Vite development server proxies API requests to the backend at `http://localhost:8080`.

### 4. Place an order

Select menu items and place an order. The backend requires at least one chef to assign preparation work.

To stop either server, press `Ctrl+C` in its terminal.
